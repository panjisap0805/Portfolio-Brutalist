# Panji Saputro — Personal Portfolio & Case Studies

A brutalist, editorial personal portfolio and product design showcase built with **Next.js (App Router)**, **React 19**, and **Tailwind CSS v4**.

Designed to present deep-dive UX/UI case studies, system architecture thinking, and complex enterprise product design with high performance and editorial typography.

---

## 📌 Featured Case Studies

- **MDS Cash** — Enterprise multi-currency treasury, cash management, and high-volume corporate payout workflows.
- **Warehouse Fulfillment** — Warehouse Management System (WMS) optimizing batch picking, pack stations, and dispatch operations.
- **CRM Helpdesk** — Omnichannel customer support workspace, automated ticketing queues, and real-time SLA monitors.
- **Warehouse Internal Freight** — Cross-hub freight tracking, line-haul dispatching, and inter-facility inventory transfers.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router, Turbopack, SSG)
- **UI Library**: [React 19](https://react.dev/)

- **Design Aesthetic**: Neo-Brutalist & Editorial Technical UI (Monospace metadata, dense data density, crisp borders, tactile micro-interactions)
- **Deployment**: Optimized for Vercel / Netlify / static hostings

## 🚀 Getting Started

### Prerequisites
- Node.js >= 18.18.0
- npm / pnpm / yarn

### Installation

```bash
# Clone repository
git clone https://github.com/panjisap0805/Portfolio-Brutalist.git

# Navigate into project directory
cd Portfolio-Brutalist

# Install dependencies
npm install
```

### Running Locally

```bash
# Start local development server
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser to view the portfolio.

### Building for Production

```bash
# Generate optimized production build
npm run build

# Start production server
npm run start
```
